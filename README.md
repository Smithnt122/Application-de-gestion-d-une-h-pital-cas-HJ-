### Application web de gestion hospitalière

## 1. Présentation du projet
Le projet est un travail de fin de cours de programmation web 1.
Il nous a été demandé de travailler en groupe de 10 personnes, de choisir un sujet.

Notre groupe a choisi une application web de gestion d'une hopital de la place et nous avons choisi HJ HOSPITAL.

## 2. Objectifs
- Gestion des patients
- Gestion des médecins
- Gestion des rendez-vous
- Gestion des consultations
- Gestion de la pharmacie
- Gestion du laboratoire
- Gestion de la facturation
- Gestion des hospitalisations

## 3. Technologies utilisées
- HTML5
- CSS3
- JavaScript
- Git et GitHub
